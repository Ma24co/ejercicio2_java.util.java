Ejercicio 02: Suma de números hasta un valor aleatorio

Desarrolle un programa en Java que genere automáticamente un número entero positivo llamado m. El valor deberá ser generado al azar entre 1 y 20.

El programa deberá mostrar en pantalla el número generado. Posteriormente, deberá calcular la suma de todos los números enteros comprendidos entre 1 y m, incluyendo ambos valores.

Para realizar la suma, el programa deberá utilizar una estructura repetitiva. Finalmente, deberá mostrar el resultado obtenido mediante un mensaje claro.
